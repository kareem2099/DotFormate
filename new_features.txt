Implemented Features:

1.  **DOCX to PPTX Conversion:**
    *   **File:** `docx_converter.py`
    *   **Description:** Added functionality to convert Microsoft Word documents (.docx) to PowerPoint presentations (.pptx) using LibreOffice.
    *   **Integration:** Updated `menu_handlers.py` to include a callback for this conversion and `main.py` to route to the new handler.

2.  **PPTX to DOCX Conversion:**
    *   **File:** `pptx_converter.py`
    *   **Description:** Added functionality to convert Microsoft PowerPoint presentations (.pptx) to Word documents (.docx) using LibreOffice.
    *   **Integration:** Updated `menu_handlers.py` to include a callback for this conversion and `main.py` to route to the new handler.

3.  **Image Resizing:**
    *   **File:** `image_processor.py` (newly created)
    *   **Description:** Implemented a function to resize images to specified dimensions using the Pillow library.
    *   **Integration:** Added `resize_image_start` and `handle_resize_input` functions in `file_handlers.py` to manage the conversation flow for resizing. Updated `menu_handlers.py` to add a "Resize Image" button for image types and `constants.py` for new conversation states (`RESIZE_INPUT`). `main.py` was updated to include the new handlers in the conversation flow.

4.  **Image Rotation:**
    *   **File:** `image_processor.py` (updated)
    *   **Description:** Implemented a function to rotate images by a specified angle using the Pillow library.
    *   **Integration:** Added `rotate_image_start` and `handle_rotate_input` functions in `file_handlers.py` to manage the conversation flow for rotation. Updated `menu_handlers.py` to add a "Rotate Image" button for image types and `constants.py` for new conversation states (`ROTATE_INPUT`). `main.py` was updated to include the new handlers in the conversation flow.

5.  **Referral System:**
    *   **Files:** `database.py`, `referral_system.py` (newly created), `.env`, `main.py`, `commands.py`
    *   **Description:** Implemented a complete referral system allowing users to invite others and track their referrals. This includes generating unique referral codes, handling deep links for referrals, and providing a `/referral` command.
    *   **Integration:**
        *   `database.py`: Updated schema with `referral_code`, `referred_by`, `referrals_count` fields and new functions (`get_user`, `increment_referrals_count`).
        *   `referral_system.py`: Encapsulates all referral logic (`generate_unique_referral_code`, `handle_referral_start`, `referral_command`).
        *   `.env`: Added `BOT_USERNAME` for referral link construction.
        *   `main.py`: Integrated `handle_referral_start` into `/start` command and registered `/referral` command.
        *   `commands.py`: Added `/referral` to the list of user commands.

6.  **Premium Features and Payment Integration**
    *   **`/payment` Command**: The bot now supports a `/payment` command, allowing users to choose from various premium subscription tiers (weekly, monthly, half-yearly, yearly) and a lifetime source code access option.
    *   **PayPal Integration**: Seamless integration with PayPal for payment processing. Users are directed to PayPal for approval, and webhooks are used to confirm payments.
    *   **Manual Payment Methods**: Support for manual payment methods like Cliq, Vodafone Cash, and Instapay, where users can send transaction screenshots for verification.
    *   **User Premium Status Management**: The database schema has been extended to store `is_premium`, `premium_type`, and `premium_expiry_date` for each user. Payment webhooks now correctly update these fields upon successful transactions.

7.  **File Size Limits**
    *   **Free User Restrictions**: Free users are now subject to file size limits for uploads:
        *   Images: 10 MB
        *   PDFs: 25 MB
        *   Word documents: 15 MB
        *   PowerPoint presentations: 30 MB
    *   **Premium User Exemption**: Premium users are exempt from all file size restrictions.

8.  **Cloudflare R2 Integration for File Storage**
    *   **Scalable File Storage**: All input and output files are now temporarily stored on Cloudflare R2, providing a scalable and efficient storage solution.
    *   **R2 Metadata Storage**: Metadata for each file uploaded to R2 (including `user_id`, `r2_object_key`, `upload_time`) is saved in a dedicated collection in the MongoDB database.
    *   **Automated Cleanup**: A daily scheduled job (`daily_r2_cleanup_job`) has been implemented in `main.py`. This job queries the database for files uploaded more than 1 week ago, deletes them from R2, and marks their entries as deleted in the database, ensuring efficient storage management.

9.  **Daily Conversion Limits**
    *   **Free User Conversion Limits**: Free users are now limited to a maximum of 5 conversions per day (`MAX_FREE_DAILY_CONVERSIONS`).
    *   **Premium User Exemption**: Premium users have unlimited daily conversions.
    *   **Limit Enforcement**: Daily conversion limits are checked at the entry points of conversion flows (`handle_document_type` for file uploads and `handle_url_input` for URL downloads) to prevent exceeding the quota.
    *   **Conversion Count Tracking**: The `daily_conversion_count` for each user is tracked and reset daily.
