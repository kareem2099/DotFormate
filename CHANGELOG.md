# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0]
### Added
- Referral system with commission rewards
- Payment gateway integration (PayPal, Cliq, Vodafone Cash, InstaPay)
- Premium subscription plans (weekly, monthly, half-yearly, yearly)
- User balance and payment tracking
- Admin payment management and pending payments view

## [0.1.1]
### Improved
- Quality of file conversions and processing
- Enhanced image compression and PDF operations
- Better error handling and user notifications
- Improved OCR accuracy and text extraction

## [0.1.0]
### Added
- Support for additional file formats (DOCX, PPTX conversions)
- OCR functionality for text extraction
- PDF merge and split operations
- Watermarking for images and documents
- URL download and conversion capabilities
- Image resize and rotate features
- Cloud storage integration (R2) for large files
- Daily cleanup job for old files

## [0.0.2]
### Added
- Basic PDF to image conversions (PNG, JPG, WebP, TIFF)
- Image to PDF conversions
- File compression functionality
- Basic file upload and processing
- User interface with conversation handlers

## [0.0.1]
### Added
- Initial project setup
- README.md with project documentation
- CHANGELOG.md for version tracking
- Basic bot structure with Telegram integration
- Database setup with MongoDB
- Admin command framework
